Tools and resources¶

This page is for people using the TIPMIP-ESM data available on DKRZ (Levante). If you have tools for working with TIPMIP-ESM data that you would like to share, please contact karoline[at]pik-potsdam.de.

It is unclear which data is available on DKRZ and which data the modelling centers will not provide.

  1. Gap list: known gaps per model, variable and experiment, including comments by the modelling centers on which data will not be provided: spreadsheet

  2. Overview of all data on DKRZ, with file paths: spreadsheet

  3. Variable finder script: python3 /work/bm1448/analysis/karo/tipmip-dkrz-data-processing/dkrz_variable_finder.py <cmip_variable_name>. Add -f to also print the file paths. All options are described in the README.

The gap list is not updated regularly, and some modelling centers did not respond (status: August 2026). The variable finder script takes some time to run.

There are no model description files for the model versions used here. Separate requests by each user cause a lot of work.

Model specification list, to be filled in by the modelling centers: spreadsheet

Not all centers have filled it in, but the existing entries are still useful.

Models reach a given warming level at different times, so results are hard to compare along the time axis.

tipmip-gwl: Open source Python library that maps TIPMIP-ESM simulations from the time axis to a common global-warming-level axis, so that models can be compared directly. Code and tutorials: https://github.com/tipmip-hub/tipmip-gwl

The accompanying paper has been submitted to GMD. Contact: Jakob Harteg (jakob.harteg[at]pik-potsdam.de)

Everyone has to do the same basic time series analysis on data with many irregularities.

TIPMIP DKRZ data processing pipeline: tipmip-dkrz-data-processing

See also the known problems per model.

CESM2 data is not CMORized.

CMORization-light tool by Karoline Ramin, on Levante at /work/bm1448/preESGF/esm/CESM2. Usage is described at the top of cesm_data_prep.py.

Advantages: simplifies data handling, already in place, available to all Levante users, some experiments are already converted.

Limitations: only the metadata of simple variables is converted (not a full CMORization), the method may be imperfect, and only a few people have write access. It works only for the simple variables listed in the CESM conversion tab of the pre-ESGF data request (limited access). Please contact karoline[at]pik-potsdam.de for problems.

Detecting abrupt shifts consistently across a large multi-model ensemble is hard, and everyone builds their own detection setup.

TOAD: open-source Python framework for detecting abrupt shifts in gridded Earth-system data. It detects shifts at grid-cell level, clusters them into coherent regions, and identifies shifts that agree across ensemble members, models or method settings. Modular, so you can plug in your own detection methods. Code, docs and tutorials: https://github.com/tipmip-hub/toad

A description paper is in review at GMD (preprint available[https://egusphere.copernicus.org/preprints/2026/egusphere-2026-356/]). Contributions are very welcome. Contact: Jakob Harteg (jakob.harteg[at]pik-potsdam.de)
