Registration as contributor¶

  1. The first step is to register your model. Instructions for this are available on the TIPMIP website.

    If you are running an Earth System Model (ESM): please note that all ESMs contributing to TIPMIP must be CMIP-registered models. This means, among other things, that they need to be registered in the CMIP CVs and have run all the DECK experiments for the corresponding CMIP iteration.

  2. Review the TIPMIP experimental protocols and the required output variables. - Get in contact with the corresponding domain leads and review the experimental protocols for that domain.
